`mochy-desktop.svg` is Mochy's launcher icon from the Android app
(`app/src/main/res/drawable/ic_launcher_mark.xml` on `ic_launcher_background`, the visible middle of
the adaptive icon) on a rounded tile for the Linux desktop. `mochy-desktop.png` is the same at 512 px,
for the window and the package: `rsvg-convert -w 512 -h 512 mochy-desktop.svg -o mochy-desktop.png`.
